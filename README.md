## Личные проекты

### Dropoly — мобильная головоломка number merge drop

[Сайт проекта](https://nightwelf.github.io/dropoly/index.html)

- Казуальная игра в жанре number merge drop: тап по колонке роняет плитку, слияние с соседями того же номинала запускает каскад с множителем очков
- 4 режима сложности (Easy/Normal/Hard/Expert) — видимость следующей плитки, частота бомб, условие проигрыша и максимальный номинал плитки
- Ежедневный челлендж на общем сиде: одинаковая последовательность плиток для всех игроков
- Прокачка: монеты и опыт открывают скины плиток, аватары, темы интерфейса; система достижений за каскады
- Полностью офлайн, без аккаунтов — прогресс, монеты и рекорды хранятся на устройстве

### Fonic — диктофон с офлайн-распознаванием речи (в разработке)

[Сайт проекта](https://nightwelf.github.io/fonic/)

- Запись, расшифровка и поиск работают полностью без сети: whisper.cpp (`whisper_ggml`) в изоляте, выбор модели на каждую запись
- Запись в foreground service с паузой из нотификации, Quick Settings Tile, восстановление записи после убийства процесса системой
- Фоновая очередь расшифровки, опция «расшифровывать ночью на зарядке», словарь терминов на запись
- Полнотекстовый поиск по расшифровкам (FTS5), плеер с перемоткой по тапу на сегмент, карта записей
- Экспорт в SRT/VTT и zip-архив с манифестом версии схемы, импорт с проверкой совместимости
- BLoC, Drift, GoRouter; запись и распознавание вынесены в собственные пакеты, waveform — `audio_waveform_kit`

### Kept — воспоминания из фото на телефоне (в разработке)

[Сайт проекта](https://nightwelf.github.io/kept/)

- Каждое утро — подборка из галереи: «в этот день», поездки, лучшее за месяц, праздники, воспоминания в лицах
- Весь анализ на устройстве (ML Kit): отбор резких кадров с лицами и улыбками, отсев дублей серийной съёмки, скриншотов и документов
- Группировка лиц по людям на телефоне; в сеть уходят только округлённые до ~1 км координаты за названием города
- Тяжёлая индексация галереи — в фоне ночью на зарядке, первое воспоминание готово примерно через минуту после настройки
- Просмотр как история с плавным приближением к лицам, коллаж для шеринга
- Без аккаунта, рекламы и аналитики

## Опубликованные пакеты

Независимо от основной работы разрабатываю и поддерживаю несколько собственных Flutter-пакетов, которые использую в том числе в текущих задачах:

### multilevel_navigator — адаптивная навигационная система

[pub.dev](https://pub.dev/packages/multilevel_navigator) · [GitHub](https://github.com/Nightwelf/multilevel_navigator)

- 4-уровневая навигация (панель — список — детали — детали) поверх go_router, с автоматическим расчётом видимости уровней под ширину экрана
- 5 режимов отображения: от floating-панели на узком экране до resizable многоколоночного layout на десктопе (SplitPane)
- Сворачивание уровней по тапу на активную фичу или при уходе с уровня на мобильных, с сохранением состояния виджета/BLoC
- Сохранение состояния: полный URI фичи при переключении, BLoC уровня — через PersistentBlocProvider, переживает скрытие/показ по адаптивным правилам
- Система модальных окон с раздельными билдерами под платформу и ширину экрана (dialog/bottom sheet), включая передачу произвольных аргументов вместо query-параметров
- Табы с автоматической синхронизацией с URL, разделение авторизованных и неавторизованных фич
- Ядро адаптивности (расчёт видимости, layout, BLoC) покрыто тестами

### chat_message_composer — композитный виджет для составления сообщений чата

[pub.dev](https://pub.dev/packages/chat_message_composer) · [GitHub](https://github.com/Nightwelf/chat_message_composer)

- Не просто текстовый редактор, а полноценный композитор сообщения: текст, вложения и режим отправки собираются в единую модель сообщения перед отправкой
- Форматирование текста (жирный, курсив, подчёркивание, зачёркивание, списки, цитаты, код, ссылки) на базе flutter_quill
- Вложения: изображения, видео и документы — выбор файлов, drag-n-drop на desktop, вставка из буфера обмена, съёмка фото с камеры
- Упоминания пользователей — панель «@» с поиском и навигацией стрелками
- Эмодзи: поиск и вставка, с заменой клавиатуры на панель эмодзи на мобильных устройствах
- Режимы composing на BLoC: обычный ввод, редактирование и цитирование/ответ на сообщение, с восстановлением черновика
- Локализация интерфейса через отдельный репозиторий строк, кастомизация под мобильный/десктопный layout

### delta_text_view — рендеринг Delta-формата в Flutter-виджеты

[pub.dev](https://pub.dev/packages/delta_text_view) · [GitHub](https://github.com/Nightwelf/delta_text_view)

- Полностью независим от конкретного текстового редактора — работает поверх лёгкого dart_quill_delta, не требуя подключать flutter_quill
- Упоминания пользователей и emoji как произвольные embed-объекты через конфигурируемые MentionConfig/EmojiConfig, без привязки к конкретной модели данных
- Выделяемый текст с получением под-Delta выделенного диапазона — например, для копирования с сохранением форматирования
- Набор extension-утилит для работы с Delta без рендеринга: подсчёт длины, обрезка по строкам, проверка упоминаний, сериализация

### fit_grid — адаптивная сетка карточек

[pub.dev](https://pub.dev/packages/fit_grid) · [GitHub](https://github.com/Nightwelf/fit_grid)

- Автоматический подбор количества столбцов/строк и размера плиток под доступное пространство, без ручного указания crossAxisCount
- Расчёт раскладки на layout-фазе (CustomMultiChildLayout) — ресайз области вызывает только relayout, без rebuild дерева виджетов
- Минимизация пустого пространства: заполнение области при нехватке элементов, максимизация размера плитки при полной странице
- Настраиваемое выравнивание через AlignmentDirectional с поддержкой RTL/LTR и отдельным выравниванием неполной последней строки
- Свои пресеты размеров плиток и брейкпоинты пагинации под mobile/tablet/desktop; без сторонних зависимостей
- Алгоритм раскладки, брейкпоинты, подбор пресета и пагинация покрыты модульными и виджет-тестами

### audio_waveform_kit — запись аудио с визуализацией в реальном времени

[pub.dev](https://pub.dev/packages/audio_waveform_kit) · [GitHub](https://github.com/Nightwelf/audio_waveform_kit)

- Запись с микрофона в один тап; чистый Dart FFT-анализ спектра в реальном времени, без нативных библиотек
- Живые визуализации во время записи: скроллящийся waveform, индикатор уровня, FFT-спектр, осциллограф сырого PCM-сигнала
- Статичные визуализации после записи: усреднённый спектр, тепловая карта спектра во времени, waveform в стиле мессенджера (RMS по окнам)
- Готовый плеер для воспроизведения записи с прогресс-баром и перемоткой, не требующий обёртки в общий scope пакета
- Полностью кроссплатформенный — включая Web (WAV-байты в памяти)
